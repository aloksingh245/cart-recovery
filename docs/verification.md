## Limits

Delivery, payment and customer/store actions are simulated. Real provider/storefront/warehouse
integration, arbitrary backdated external ingestion, public deployment hardening and causal-lift
experiments are outside this local application. Roles share the configurable local-demo password.
The owner must still review the work, choose a public GitHub destination if submitting, and export the
complete session transcript. No real messages, personal data, public publishing or human-review claims
are included in these checks.
